📖 1-1.1 多項式核心名詞字典

1. 不定元 (Indeterminate)

多項式中代表抽象數值的文字符號（如 $x, y$）。不同於方程式中求解的未知數，它是代表運算的文字基底。

2. 常數多項式 (Constant Polynomial)

不含不定元的常數多項式 $f(x) = c$，包含兩大類：
① 零次多項式：當 $c \neq 0$（例如 $f(x) = 8$ 或 $-5$），是常數多項式，次數定為 0 次。
② 零多項式：當 $c = 0$（即 $f(x) = 0$），也是常數多項式，次數不予討論（無意義）。
核心結論：「零次多項式」與「零多項式」兩者皆屬於「常數多項式」。

3. 單元多項式的標準形式與四大禁區

單元多項式的標準形式寫法：
$$f(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0 \quad (a_n \neq 0)$$ 標準形式的兩大必要條件：
• 指數條件：次方 $n$ 必須為非負整數 ($0, 1, 2, 3, \dots$)。
• 係數條件：係數 $a_n, a_{n-1}, \dots, a_0$ 必須為實數，且領導係數 $a_n \neq 0$。

多項式四大禁區（不定元文字不可出現在）：
① 分母（如 $\frac{1}{x} = x^{-1}$，違背非負整數指數條件）
② 根號內部（如 $\sqrt{x} = x^{1/2}$，違背整數指數條件）
③ 指數位置（如 $2^x$）
④ 絕對值內部（如 $|x|$）

• 排列規範：可依降冪排列（次方由高到低）或升冪排列（次方由低到高）呈現。

4. 同類項 (Like Terms) 辨識

所含不定元字母相同，且對應次方也完全相同的項稱為同類項。例如：$3x^2$ 與 $-7x^2$ 為同類項。

5. 智慧單位模型 (Smart Unit Model)

當題目指定了特定大單位（例如「百萬元」或「公噸」）時，多項式中的數值係數即代表該單位的倍數，列式時不重複書寫單位。
