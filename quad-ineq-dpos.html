觀念統整：一元二次不等式解法步驟

  • 二次項係數化為正數（互動練習）：確保最高次項係數為正數。若遇到 a = -1，將兩邊同乘以 -1，同時將不等號方向翻轉（例如：> 翻轉為 <）。
  • 因式分解求邊界：利用十字相乘法拆解成 (x + a)(x + b) 形式，求得兩邊界根 x = p, q。
  • 數線點位繪製：將兩根標記於數線上。不含等號（<, >）畫空心點；含等號（≤, ≥）畫實心點。
  • 正負區間分界：二次項係數為正時，數線右側由右至左依序填入「正 → 負 → 正」。
  • 選取解集：整理後的式子「> 0 取正數區間（兩側）」；「< 0 取負數區間（中間）」。
