  2. 步驟二：算判別式 (D = b2 - 4ac) 確定交點
    • D > 0：相交於兩點 (α, β)
    • D = 0：相切於一點 (α)
    • D < 0：沒有交點（浮在 x 軸上方）
  3. 步驟三：看圖寫解集
    • 求 > 0 或 ≥ 0 ➔ 取軸上方（畫實線）。
    • 求 < 0 或 ≤ 0 ➔ 取軸下方（畫實線）。
    • 含等號用實心點，不含等號用空心點。
