📐 絕對值不等式大冒險

🧠 闖關觀念統整指南

  • 幾何意義：絕對值 |x| 代表數線上點 x 與原點 0 的距離。
  • 夾中間（小於型）：|x| < a 表示距離小於 a，範圍夾在兩點之間：-a < x < a。
  • 向外擴（大於型）：|x| > a 表示距離大於 a，範圍向兩側外擴：x < -a 或 x > a。
  • 數線圖示規範：無包含等於號（<, >）時，端點必須以空心圓表示。
  • 多步驟拆解原則：求解如 |2x + b| < c 時，遵循三大步驟：
    ① 去絕對值 ➔ ② 移項消常數 ➔ ③ 同除係數求解。
